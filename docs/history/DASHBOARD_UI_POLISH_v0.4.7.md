# PRISM LINK Dashboard UI Polish v0.4.7

This update tidies the Salon-first MVP dashboard to match the approved light/narrow operational layout used in the latest UI reference.

## Changes

- Added a compact navy PRISM LINK header and tenant badge.
- Restyled navigation into compact tab buttons with a clear active state.
- Added a cleaner readiness/status banner.
- Rebuilt Salon setup into a responsive two-column layout.
- Reworked Business hours into compact day/open/close/closed rows.
- Added **Copy Monday to weekdays** for faster salon setup.
- Moved service creation behind an **Add service** control and changed services to a compact list/table.
- Moved staff creation behind an **Add staff** control and changed staff to a compact list/table.
- Added consistent Active status pills for configured services/staff.
- Kept Google Calendar and live voice readiness visible below the core salon setup.
- Improved spacing, borders, shadows, typography and mobile responsiveness.
- Preserved all existing v0.4.6 voice/runtime behavior and APIs.

No database migration or environment-variable change is required.
